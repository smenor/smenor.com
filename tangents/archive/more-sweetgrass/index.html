Sweetgrass

Sweetgrass is a way to build and host Internet-scale pages and services using a secure, peer-to-peer storage, processing, and distribution method.

Sweetgrass is a self-healing protocol which provides verifiable authorship, integrity, [authentication](https://en.wikipedia.org/wiki/Authenticated_encryption, consistency, validation, causality preservation, unlinkability, repudiation, and asynchronicity.

It is deliberately not intended to be anonymous and does not support confidentiality, repudiation

The initial release of Sweetgrass Core consists of static object storage, distribution, and routing packeged for Docker containerization.

Overview

Every device participating in a Sweetgrass network

Identity

Every participating Sweetgrass device has a long-lived signing identity public-private key pair.

Individuals and group identity are federated over one or more devices using additional long-lived keys pairs, one retained on each device, and one distributed distributed using Diffie–Hellman handshake and multicast encryption.

Replication

Routing

Sweetgrass uses standard DNS along with Distributed Identitifiers to allow routing and distribution of group membership and individual identity.

Memory and Performance

Sweetgrass is designed to provide a cryptographically secure system for replication and distribution of versioned static objects with minimal performance requirements taking advantage of web / Internet caching and multicast distribution.

It requires almost minimal overhead on top of arbitrary object storage and distribution adding minimal additional metadata.

The primary intended use for Sweetgrass Core is to allow untrusted servers to replicate, store, and distribute static verifiably signed HTML / text files.

In the next iteration, Sweetgrass will add multicasting to support Internet-scale broadcasts with verifiable authorship.
